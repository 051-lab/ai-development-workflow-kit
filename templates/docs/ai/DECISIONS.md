# Decisions

> Durable record of decisions that should not be repeatedly reopened without new evidence.

## How to Use This File
For each meaningful decision, record the date, decision, reason, alternatives considered when relevant, and consequences. Append new entries rather than silently rewriting history. If a decision changes, add a superseding entry that points back to the earlier one.

## Decision Entry Format
### YYYY-MM-DD — Short decision title
- **Decision:** State what was chosen.
- **Reason:** Explain the evidence or constraint that drove the choice.
- **Alternatives:** Note serious alternatives that were rejected, when useful.
- **Consequences:** Record important follow-on constraints or tradeoffs.
- **Supersedes:** Record an earlier decision only when this entry replaces one.
